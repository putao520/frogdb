# FrogDB

[![Crates.io](https://img.shields.io/crates/v/frogdb)](https://crates.io/crates/frogdb)

FrogDB is a graph, document, and vector hybrid embedded database. It is a fork
of [cozodb/cozo](https://github.com/cozodb/cozo) at commit `481af05`, licensed
under MPL-2.0 and maintained by frog-build.

This crate contains the implementation proper of FrogDB.
